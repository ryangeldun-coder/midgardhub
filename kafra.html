Meet Kafra

Kafra is a free Discord bot that puts the whole Midgard Community Hub database inside your server. Ask her about any Ragnarok Zero item, drop, monster, spawn map or refine chance with a single /kafra command - no more alt-tabbing mid-conversation - and set MVP respawn timers that ping you before the boss is back.

What Kafra can do

Every command starts with /kafra. Type it in any channel and Discord shows you the list - you never have to memorise these.

/kafra item <name>

Everything about an item - stats, type, description, and a few of the monsters that drop it.

Example: /kafra item Iron
/kafra farm <item>

Where to get an item: every monster that drops it, the drop rate, and the maps that monster spawns on.

Example: /kafra farm Jellopy
/kafra monster <name>

A monster's full card - level, HP, element, race, size, EXP, spawn maps and its whole drop table.

Example: /kafra monster Poring
/kafra where <monster>

Just the spawn maps for a monster, grouped by zone.

Example: /kafra where Poring
/kafra map <id>

What spawns on a given map. Use the map id, e.g. prt_fild08.

Example: /kafra map prt_fild08
/kafra refine <level> [item]

The success chance for a +N refine step. Name the item and Kafra uses the right table - armor and each weapon level have different rates.

Example: /kafra refine 8 Iron Cannon
/kafra bosstimer <boss> <minutes> <channel>

Log an MVP kill and Kafra pings you in that channel about 5 minutes before it respawns. You give the respawn time in minutes and the in-game channel it died on (Main, A-D, Y, Z).

Example: /kafra bosstimer Phreeoni 117 B
/kafra bosses

Lists every boss timer running on your server - which boss, which channel, and when each one is due.

Example: /kafra bosses
/kafra bossclear <boss> [channel]

Cancels a boss timer you set. Name the channel too if you only want to clear one of them.

Example: /kafra bossclear Phreeoni
/kafra help

Lists every command Kafra knows. Type just /kafra to get the same thing.

Example: /kafra help

Boss timers

Kill an MVP, run /kafra bosstimer, and Kafra logs it in the channel and pings you there roughly 5 minutes before it comes back. You type the respawn time yourself (in minutes) and pick the in-game channel it died on. Ragnarok Zero's exact MVP timers aren't all confirmed yet, so treat them as best guesses until the community pins them down.

  • Only the person who set the timer gets pinged.
  • One live timer per boss per in-game channel - logging the same kill again just resets it.
  • /kafra bosses shows what's running; /kafra bossclear cancels one.
  • Old timers are wiped automatically - nothing piles up in your server.
This is the one feature that needs a permission. A reminder that fires half an hour after you run the command has to be posted somehow, so Kafra installs with permission to post messages. It still has no way to read your conversations and no moderation powers (see below). Servers that added Kafra in the first days - before this existed - should click the install link once more to pick it up.

How to add Kafra - step by step

1

Click the button

Hit Add Kafra to your server above (or this link). It opens Discord in a new tab. If you are not logged in, log in first.

2

Pick your server

A window titled “An external application wants to access your Discord account” appears. Open the “Add to Server” dropdown and choose the server you want Kafra in.
You only see servers where you are the owner or have the Manage Server permission.

3

Authorize

Click Continue, then Authorize. Kafra asks to add slash commands and to post messages - the second one is what lets boss-timer reminders work. It gets no role, cannot read your conversations, and cannot kick, ban or change anything.

4

Pass the human check

If Discord shows an “I am human” checkbox, tick it. That is it - Kafra is now in your server.

5

Use it

Go to any channel and type /kafra. Discord shows the list of commands - pick one, type what you are looking for, press Enter. The answer appears in the channel with a link back to this site.
On a brand-new install the commands can take up to a minute to show up. If they do not, fully close and reopen Discord.

Is it safe?

Can't read your chat

Kafra can post in channels (for boss reminders) but has no Message Content Intent and no gateway - it can't see what people say, can't see members, gets no role, and can't moderate.

Barely speaks

It replies to /kafra. The only unprompted message it ever sends is a boss-timer reminder someone on your server set.

Free

No paywall, no premium tier, no ads in the replies.

Is it safe? What can Kafra do in my server?

Kafra can add slash commands and post messages in channels. It has no gateway connection and no Message Content Intent, so it cannot read what people say, cannot see your member list, has no role, and cannot kick, ban or change anything. The only messages it sends are a reply to /kafra and a boss-timer reminder someone on your server scheduled.

How do the boss timers work?

Run /kafra bosstimer with the boss name, how many minutes until it respawns, and the in-game channel. Kafra logs the kill in that channel and pings whoever set it roughly 5 minutes before the respawn. /kafra bosses lists what's running, /kafra bossclear cancels one. Respawn times are typed by hand because Zero's exact MVP timers aren't all confirmed yet.

Does it cost anything?

No. Kafra is completely free and always will be.

Where does the data come from?

Straight from midgardhub.com - the exact same database that powers this website. When the site's data is updated, Kafra picks it up automatically.

Can I use Kafra without adding it to a server?

Yes. On the install screen choose “Add to My Apps” instead of a server, and /kafra will work for you in DMs and in any server you are in.

The commands are not showing up.

Give it a minute after adding it. Make sure you actually have the Manage Server permission on that server. Then quit Discord completely and reopen it - the command list refreshes on restart.
